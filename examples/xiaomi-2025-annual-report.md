# 2025年小米年度报告

## 一、执行摘要

2025年，小米围绕“人车家全生态”持续推进业务升级，收入和利润均创历史新高。全年总收入为 **4,572.9亿元**，同比增长25.0%；毛利为 **1,018.1亿元**，同比增长33.0%，毛利率提升至 **22.3%**；按国际财务报告准则计算的年度利润为 **415.7亿元**，同比增长76.3%；经调整净利润为 **391.7亿元**，同比增长43.8%。

业务结构出现明显变化：智能手机×AIoT分部收入为 **3,512.2亿元**，同比增长5.4%；智能电动汽车、人工智能及其他新业务分部收入达到 **1,060.7亿元**，同比增长223.8%，占集团总收入的23.2%。小米正在从以智能手机为主的消费电子公司，向连接手机、AIoT、汽车与人工智能的综合科技平台转型。

## 二、关键财务指标

| 指标 | 2025年 | 2024年 | 同比变化 |
| --- | ---: | ---: | ---: |
| 总收入 | 4,572.9亿元 | 3,659.1亿元 | +25.0% |
| 毛利 | 1,018.1亿元 | 765.6亿元 | +33.0% |
| 毛利率 | 22.3% | 20.9% | +1.4个百分点 |
| 营业利润 | 479.0亿元 | 245.0亿元 | +95.5% |

| 经调整净利润（非IFRS） | 391.7亿元 | 272.3亿元 | +43.8% |
| 经营活动产生的现金净额 | 341.4亿元 | 393.0亿元 | -13.1% |

## 三、分业务表现

### 1. 智能手机：规模稳定，盈利承压

智能手机业务收入为 **1,864.4亿元**，同比下降2.8%；全年出货量为 **1.652亿部**，同比下降2.0%。根据Omdia数据，小米连续第五年保持全球智能手机出货量前三，全球市场份额为13.3%。

智能手机毛利率由2024年的12.6%降至 **10.9%**，主要受到中国大陆补贴变化、关键零部件价格上涨和全球市场竞争加剧影响。手机仍是小米最大的单一产品收入来源，但其增长逻辑正从单纯扩大出货量转向提升高端产品占比、产品差异化和生态协同价值。

### 2. IoT与生活消费产品：生态规模继续扩大

IoT与生活消费产品收入为 **1,232.0亿元**，同比增长18.3%，毛利率提升至 **23.1%**。平板、可穿戴设备和智能大家电共同推动增长：平板收入同比增长30.2%，智能大家电收入同比增长23.1%，可穿戴产品收入同比增长30.7%。

截至2025年末，小米AIoT平台连接设备数量达到 **10.792亿台**（不含智能手机、平板和笔记本），同比增长19.3%；连接5台及以上设备的用户达到 **2,270万**，同比增长23.6%。

### 3. 互联网服务：高毛利业务保持增长

互联网服务收入为 **374.4亿元**，同比增长9.7%，毛利率为 **76.5%**。2025年12月，全球月活跃用户达到 **7.541亿**，同比增长7.4%；中国大陆月活跃用户达到 **1.904亿**。广告业务收入为 **285.0亿元**，同比增长15.2%，海外互联网服务收入达到 **126.0亿元**，同比增长15.2%。

互联网服务继续发挥高毛利和用户变现作用，是小米生态规模扩大后重要的利润支撑。

### 4. 智能电动汽车、AI及其他新业务：成为新增量核心

智能电动汽车、人工智能及其他新业务收入为 **1,060.7亿元**，同比增长223.8%；其中智能电动汽车收入为 **1,033.0亿元**。全年智能电动汽车交付量达到 **411,082辆**，同比增长200.4%；该分部毛利率提升至 **24.3%**，并首次实现分部经营利润，金额约为 **9亿元**。

截至2025年末，小米在中国大陆已开设 **477家智能电动汽车销售中心**，覆盖138个城市。汽车业务已从投入期进入规模化交付和经营效率验证阶段，但后续仍需要持续观察产能、质量、服务网络和产品迭代能力。

## 四、“人车家全生态”战略进展

小米以智能手机和AIoT为基础，将汽车和人工智能纳入同一生态体系：

- **人**：通过手机、平板、可穿戴设备和互联网服务触达用户。
- **车**：以智能电动汽车拓展新的出行入口和高价值硬件场景。
- **家**：通过家电、智能家居和AIoT设备形成持续连接。
- **智能化底座**：以人工智能、系统软件、芯片和智能制造支撑跨设备协同。

从收入结构看，智能电动汽车、AI及其他新业务占比由2024年的9.0%提升至2025年的23.2%，说明该战略已经从概念布局进入收入贡献阶段。

## 五、研发与技术投入

2025年研发费用为 **331.3亿元**，同比增长37.8%；截至年末研发人员达到 **25,457人**，全职员工总数为 **56,531人**。过去五年累计研发投入达到 **1,055亿元**。

研发投入重点覆盖手机与AIoT、汽车核心技术、人工智能、操作系统、芯片、智能制造和基础软件。短期看，高研发投入会提高费用压力；长期看，能否形成可复用的平台技术、稳定的产品溢价和跨业务协同，是衡量投入回报的关键。

## 六、现金流与资本配置

2025年经营活动产生的现金净额为 **341.4亿元**。年末现金及现金等价物为 **269.1亿元**，现金资源合计为 **2,326亿元**；集团资产负债表处于净现金状态，年末杠杆率为 **-21.3%**。

全年资本开支为 **181.6亿元**，其中智能手机×AIoT分部为61.3亿元，智能电动汽车、AI及其他新业务分部为120.2亿元。资本投入明显向汽车、AI和新业务倾斜，同时也带来了库存、产能爬坡和投资回报周期延长等管理要求。

## 七、主要风险与关注点

1. **智能手机竞争与利润率风险**：出货量和手机收入下降，组件成本、价格竞争和区域结构变化可能继续压缩手机毛利率。
2. **汽车规模化执行风险**：交付快速增长后，产能、质量、售后服务、供应链和渠道建设需要同步扩张。
3. **研发与资本开支回报风险**：汽车和AI投入增长较快，未来需要通过产品销量、软件服务和生态协同形成持续回报。
4. **全球经营与合规风险**：关税、地缘政治、汇率、数据与产品监管变化可能影响海外市场、供应链和经营成本。
5. **现金流与库存管理风险**：经营现金流同比下降，库存增加对资金周转和需求预测提出更高要求。

## 八、年度结论

2025年是小米业务结构转折的一年：智能手机基本盘保持全球竞争力，IoT和互联网服务持续扩大生态价值，智能电动汽车和AI新业务则成为收入与利润增长的新引擎。全年收入、毛利和经调整净利润创历史新高，说明“人车家全生态”已开始转化为可量化的经营成果。

下一阶段的核心观察点包括：智能手机毛利率能否企稳，汽车业务能否在扩大交付的同时保持质量与盈利，AI和研发投入能否沉淀为跨产品能力，以及庞大用户与设备规模能否持续转化为服务收入和长期现金流。
